# 1. Ventajas de HTML5

## 1. ¿Cuales son las ventajas de HTML5?

### Principales ventajas:

- **Multimedia integrada**: Soporte nativo para audio y video.
- **Diseño semántico**: Nuevas etiquetas como `<header>`, `<footer>`, `<article>`, `<nav>`, etc., que hacen el código más claro y fácil de entender.
- **Compatible con dispositivos móviles**: Pensado para diseño adaptable (responsive design) y compatible con pantallas de diferentes tamaños.
- **Mayor rendimiento**: Menor dependencia de plugins externos y mejor integración con CSS y JavaScript.

## 2. ¿Por qué utilizar HTML5?

Usar HTML5 es prácticamente obligatorio hoy en día para desarrollar sitios web modernos. HTML5 es el estandár actual de la web, eliminando tecnologias en desuso como Flash y es compatible con navegadores modernos y dispositivos moviles. Su estructura semantica es sencilla y facil de mantener, lo que lleva a mejores y mas longevos productos. 

## 3. Ventajas:

1. Soporte nativo para audio y video.
2. Estructura semántica clara.
3. Compatible con todos los navegadores modernos y moviles.
4. Mayor rendimiento.
